# Conteúdo bruto

Material original que chega da Juliana: fotos, textos, logo. **Nada daqui vai
para o Git** (só este README e o modelo de ficha), porque foto em resolução
cheia pesa centenas de MB. Daqui o material é otimizado e segue para o lugar
certo: fotos de imóvel para o Storage do Supabase, e logo e fotos da Juliana
para `apps/site/public`.

```
conteudo/
  imoveis/       um imóvel por pasta (copie a _MODELO)
  marca/         logo (de preferência SVG ou PDF vetorial), cores, assinatura
  fotos-juliana/ fotos profissionais da Juliana, na maior resolução que tiver
```

## Imóveis

1. Copie a pasta `imoveis/_MODELO` e renomeie a cópia com algo que identifique
   o imóvel, por exemplo `apto-meia-praia-3q`.
2. Preencha a `ficha.md`.
3. Jogue as fotos em `fotos/`, na ordem em que devem aparecer: `01.jpg`,
   `02.jpg`... A `01` é a capa.

**Só entra imóvel com autorização do proprietário para anunciar.** Anunciar
imóvel sem autorização é infração no Código de Ética do CRECI.
